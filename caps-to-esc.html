Caps Lock → Escape

Repurpose Caps Lock as an Escape key. Your pinkies (and your Vim workflow) will thank you.

The alias

We define a reusable alias called caps-to-esc using the tap-hold action:

(defalias caps-to-esc
  (tap-hold 100 100 esc esc)
)

How tap-hold works

tap-hold takes four arguments: (tap-hold timeout permissive-hold tap hold). Tap outputs the tap action on a quick press-and-release; holding outputs the hold action. Both are set to esc here.

ValueMeaning
first 100Timeout (ms): press longer than this and it counts as a hold
second 100Permissive-hold window (ms): another keypress within this window triggers the hold action
first escAction on tap → sends Esc
second escAction on hold → also Esc

Wiring it up

Since tap and hold are identical here, the timing behaves transparently: a quick tap gives Escape, and there's no downside to a longer press. Drop the alias into a full, minimal config:

(defcfg process-unreleased-keys yes)

(defsrc caps
(deflayer base
  @caps-to-esc
)

(defalias caps-to-esc
  (tap-hold 100 100 esc esc)
)
💡 The @ prefix is how layers reference actions defined in defalias.

Trying it out

  • Save the config (e.g. kanata.kbd)
  • Run kanata -c kanata.kbd (on Windows, launch as administrator)
  • Tap Caps Lock in any editor — you should see Esc

Taking it further

A common upgrade is making Caps Lock Escape when tapped, Control when held:

(defalias caps-to-esc-ctrl
  (tap-hold 100 100 esc lctl)
)

Same alias structure — just change the hold action. Great for Ctrl+anything chords without stretching your pinky.
