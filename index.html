Caps Lock → Escape

Turn Caps Lock into an Escape key — a must-have tweak for Vim users and terminal dwellers.

What is Kanata?

Kanata is a keyboard remapping daemon for Windows, macOS, and Linux. You describe your desired key behavior in a plain-text configuration file, and Kanata intercepts and transforms your keystrokes system-wide — no driver hacking required.

Anatomy of a config

(defcfg        ; global settings, e.g. process-unreleased-keys
(defsrc caps   ; the physical keys you want to act on
(deflayer base ; how those keys behave in this layer
(defalias      ; reusable actions, referenced with @name
ℹ️ Every tutorial here assumes a working Kanata installation. Grab binaries or build from source from the official repo: github.com/jtroo/kanata. On Linux you'll need uinput permissions; on Windows run as administrator for it to work everywhere.
